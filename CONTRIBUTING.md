# Contributing

Issues are welcome. That includes bug reports, false alarms or misses on your own documents, and feature requests. A
small example that reproduces the problem helps; please don't paste confidential text.

Pull requests are not accepted yet. Accepting outside code needs a contributor license agreement, and there isn't one
in place. If you have a fix, describe it in an issue.

Security problems: please don't open a public issue. See `SECURITY.md`.
